Images needed for /case-rivet/. Export each from the Rivet Figma file
(https://www.figma.com/design/1luBtOW2s3XU44qxIqpa8m) and save with these
exact filenames.

In this folder (images/case-rivet/):

1. rivet-foundations.png
   Page: "Foundations"
   Select the whole page content (all 5 sections: Colors Light, Colors
   Dark, Typography, Spacing & Radius, Elevation) and export at 2x.

2. rivet-button.png
   Page: "Button"
   Select the "Button" component set (12 variants) and export at 2x.

3. rivet-modal.png
   Page: "Modal & Tooltip"
   Select the "Modal" component set (3 size variants) and export at 2x.

In ../covers/ (images/covers/), matching your other case studies' cover
banners (wide, ~1600x600 crop):

4. rivet-cover.png
   A wide banner crop — the color palette swatches or the Button variant
   grid both work well cropped to a ~8:3 aspect ratio. This is what shows
   in the case study hero and the homepage thumbnail.

How to export from Figma: select the frame/component set on the canvas,
then in the right panel scroll to "Export," set format to PNG and scale
to 2x, and click Export.
